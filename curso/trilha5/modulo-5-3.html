📄 claude.md como System Prompt

O arquivo claude.md na raiz do projeto e lido automaticamente pelo agente quando voce abre o projeto. Ele funciona como um system prompt persistente que define o contexto, regras e comportamento do agente para aquele projeto especifico.

📝 Estrutura Recomendada

# Agent Instructions
Voce esta trabalhando no framework WAT...
## The WAT Architecture
Explicacao das 3 camadas...
## How to Operate
1. Look for existing tools first
2. Learn and adapt when things fail
3. Keep workflows current
## File Structure
Onde cada tipo de arquivo vai...
## Bottom Line
Resumo do papel do agente...

💡 Dica

Sem claude.md, o agente e generico. Com um bom claude.md, ele entende seu projeto, suas convencoes e o framework que voce usa. Invista tempo criando um bom claude.md.

2

🎯 Plan Mode Detalhado

Em Plan Mode, Claude dedica mais recursos computacionais para pensar antes de agir. Ele analisa arquivos, pesquisa na web, considera alternativas e formula um plano completo antes de propor qualquer implementacao.

O que Claude Faz em Plan Mode

🔍 Analisa

Le a estrutura do projeto, arquivos existentes, workflows e tools

🌐 Pesquisa

Busca documentacao de APIs, best practices, exemplos

❓ Pergunta

Faz perguntas sobre detalhes que voce pode nao ter pensado

📋 Planeja

Cria um plano detalhado com tools necessarios e sequencia

Quando Usar Plan Mode

  • •Inicio de novos projetos ou automacoes
  • •Tarefas que envolvem multiplas APIs ou integraces
  • •Quando voce nao tem certeza da melhor abordagem
  • •Mudancas arquiteturais significativas
3

❓ Perguntas do Agente

Uma das funcionalidades mais uteis do Plan Mode e que Claude faz perguntas clarificadoras. Ele identifica lacunas na sua descricao e pede informacoes que voce pode nao ter pensado em fornecer.

💬 Exemplo de Perguntas

Canais: "Quais canais de YouTube voce quer rastrear? Devo descobrir automaticamente ou voce tem uma lista?"
Frequencia: "Com que frequencia o relatorio deve ser enviado? Diario, semanal, mensal?"
Formato: "Voce prefere PDF, PowerPoint ou ambos? Deve ser enviado por email ou salvo em algum lugar?"
Dados: "Quer manter historico em Google Sheets para analises futuras?"

💡 Dica

Responda as perguntas com o maximo de detalhes possivel. Quanto mais contexto voce der, melhor sera o plano. Nao tenha pressa nesta etapa.

4

✅ Auto-Accept Changes

Apos revisar e aprovar o plano de Claude, voce pode usar auto-accept para deixar ele executar todas as mudancas sem pedir confirmacao a cada passo. Isso acelera drasticamente a implementacao.

✓ Quando Usar Auto-Accept

  • • Apos revisar o plano cuidadosamente
  • • Em projetos novos/isolados
  • • Quando voce confia na abordagem proposta
  • • Para tarefas bem definidas

✗ Quando NAO Usar

  • • Sem revisar o plano primeiro
  • • Em projetos de producao criticos
  • • Quando o plano parece incompleto
  • • Se voce nao entendeu alguma parte

⚠️ Atencao

Nunca use auto-accept sem ler o plano. O agente vai executar exatamente o que foi planejado - se o plano estiver errado, voce tera que desfazer tudo.

5

📊 To-Do List Visual

Durante a execucao, Claude cria uma lista de tarefas visual e vai marcando cada item conforme completa. Isso permite acompanhar o progresso e saber exatamente em que ponto a automacao esta.

Exemplo de To-Do List

✓ Criar estrutura de pastas
✓ Instalar dependencias (pip install)
✓ Criar fetch_youtube_data.py
→ Criar analyze_data.py (em andamento)
○ Criar generate_charts.py
○ Criar send_email.py
○ Criar workflow markdown
○ Testar pipeline completo

💡 Dica de Produtividade

A lista visual permite voce trabalhar em outra coisa enquanto a automacao roda. Verifique periodicamente o progresso e intervenha apenas se algo der errado.

6

🔁 Iteracao de Planos

Voce nao precisa aceitar o primeiro plano. Se algo nao parece certo, peca ajustes. Iterar no plano e muito mais barato do que refazer apos implementado.

1

Revise o Plano

Leia cada tool proposto, a sequencia de execucao e os outputs esperados

2

Peca Ajustes

"Adicione tambem export para Google Sheets" ou "Use PDF em vez de PowerPoint"

3

Confirme e Execute

So aceite quando o plano refletir exatamente o que voce precisa
