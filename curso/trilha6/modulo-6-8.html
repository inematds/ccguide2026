⌨️ Slash Commands (/clear, /compact, /resume)

Comandos que comecam com / fazem coisas especiais. Estes sao os mais importantes para memorizar!

📋 Comandos Essenciais

/clear

Limpa a conversa e comeca do zero

/compact

Resume a conversa para economizar espaco

/resume

Continua uma sessao anterior

/context

Mostra quanto contexto foi usado

/help

Lista todos os comandos disponiveis

/init

Cria CLAUDE.md automaticamente

🔒 Security Review

Claude pode analisar seu codigo procurando vulnerabilidades de seguranca!

🛡️ Como Pedir uma Review

"Faca uma revisao de seguranca completa deste projeto. Procure por vulnerabilidades como SQL injection, XSS, senhas expostas, e boas praticas de seguranca."

Claude vai analisar cada arquivo e reportar problemas encontrados!

🔍 O Que Claude Procura

  • •Senhas e chaves expostas no codigo
  • •Vulnerabilidades de injecao (SQL, XSS)
  • •Configuracoes inseguras
  • •Dependencias desatualizadas

🔔 Hooks para Sons

Hooks sao scripts que rodam automaticamente. Voce pode configurar para tocar um som quando Claude termina!

🎵 Exemplo de Hook de Notificacao

Crie um arquivo .claude/hooks/on-complete.sh:

#!/bin/bash

# Mac: toca um som de notificacao

afplay /System/Library/Sounds/Glass.aiff

Muito util quando Claude esta trabalhando em algo demorado!

💡 Outros Usos para Hooks

  • •Enviar notificacao push para celular
  • •Rodar testes automaticamente
  • •Fazer backup antes de mudancas

⚙️ settings.json e Modular Building

O arquivo settings.json controla todas as configuracoes do Claude Code. Modular building e a arte de construir em partes organizadas.

📁 Onde Fica o settings.json

Global (todas as pastas):

~/.claude/settings.json

Por projeto:

.claude/settings.json

🏗️ Modular Building

A ideia de construir em partes pequenas e independentes:

  • 1.Divida o projeto em modulos (header, footer, paginas)
  • 2.Peca para Claude fazer um modulo de cada vez
  • 3.Teste cada modulo antes de continuar
  • 4.Integre os modulos no final
