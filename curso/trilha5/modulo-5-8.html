1

📺 YouTube Analytics Exemplo

Este projeto demonstra todo o poder do framework WAT: uma automacao que analisa canais de YouTube, identifica tendencias e gera relatorios profissionais semanalmente.

🎯 O que a Automacao Faz

  • 1.Descobre os principais canais de AI no YouTube automaticamente
  • 2.Coleta metricas dos ultimos videos (views, likes, engajamento)
  • 3.Analisa tendencias e identifica o que esta funcionando
  • 4.Gera graficos e apresentacao visual com branding
  • 5.Envia por email e salva historico em Google Sheets

Por que Este Exemplo?

Ele integra todos os conceitos da trilha: Plan Mode, Tools Python, APIs, transformacao de dados, geracao de documentos, envio de email, Google Sheets e deploy no Modal.

2

🔎 Scraping + Analise + Slides

O pipeline de dados tem 7 tools especializados, cada um fazendo uma unica coisa bem feita. O workflow orquestra a execucao na ordem correta.

Tools do Pipeline

discover_channels.py

Busca canais de AI automaticamente

fetch_youtube_data.py

Coleta videos e metricas via API

analyze_data.py

Processa e calcula tendencias

generate_charts.py

Cria visualizacoes com matplotlib

generate_slides.py

Monta apresentacao/PDF

export_sheets.py

Salva dados no Google Sheets

send_email.py

Envia relatorio final via Gmail

3

📄 PDF Geracao

Usando o Canvas Design Skill, a automacao gera PDFs profissionais com graficos incorporados, logo da empresa e formatacao visual atraente.

5

📊 Google Sheets Export

Todos os dados coletados sao exportados para Google Sheets, permitindo analises adicionais, compartilhamento com equipe e construcao de historico.

📑 Abas Criadas

Channel Stats
ID, nome, subscribers, total views, video count
Top Videos
ID, titulo, canal, views, likes, comments, engagement
Weekly Summary
Data, canais, videos, median views, top keywords

Beneficios do Sheets

  • • Historico: Cada execucao adiciona novos dados
  • • Compartilhavel: Equipe pode acessar sem login especial
  • • Dashboards: Crie graficos nativos do Sheets
  • • Integravel: Conecte com outras automacoes
