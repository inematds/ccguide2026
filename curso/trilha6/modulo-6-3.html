🌐 Node.js Download

Node.js e um programa que permite rodar JavaScript no seu computador. Claude Code precisa dele para funcionar - e o primeiro e mais importante passo!

📥 Passo a Passo

1

Acesse nodejs.org

Abra seu navegador e va para https://nodejs.org

2

Clique em "LTS" (versao recomendada)

LTS significa Long Term Support - e a versao mais estavel

3

Execute o instalador

Clique no arquivo baixado e siga as instrucoes (Next, Next, Install...)

✅ Como Verificar se Funcionou

Abra o terminal (Prompt de Comando no Windows, Terminal no Mac) e digite:

node --version

Se aparecer algo como "v20.x.x", deu certo!

2

📥 npm install claude

npm e como uma "loja de apps" para programas de terminal. Com um comando simples, voce baixa e instala o Claude Code. E mais facil do que parece!

⌨️ O Comando Magico

Abra o terminal e digite exatamente isso:

npm install -g @anthropic-ai/claude-code

npm - o gerenciador de pacotes

install - comando para instalar

-g - global (disponivel em qualquer pasta)

@anthropic-ai/claude-code - o pacote do Claude Code

⏳ O Que Vai Acontecer

Voce vai ver um monte de texto rolando na tela - isso e normal! Sao os arquivos sendo baixados. Aguarde ate aparecer algo indicando que terminou (geralmente volta para a linha de comando normal).

3

🖥️ Warp como Alternativa

Se o terminal padrao te assusta, o Warp e uma alternativa muito mais bonita e amigavel. E gratis e feito especialmente para quem esta comecando!

Terminal Tradicional

  • • Interface simples e datada
  • • Texto branco em fundo preto
  • • Sem ajuda visual
  • • Pode ser intimidador

Warp Terminal

  • • Interface moderna e bonita
  • • Autocompletar inteligente
  • • Historico visual
  • • IA integrada para ajudar

💡 Como Instalar o Warp

Acesse warp.dev, baixe e instale. Disponivel para Mac, Linux e Windows. E 100% gratis para uso pessoal!

4

▶️ Primeiro Comando "claude"

Este e o momento magico! Depois de instalar, voce digita "claude" no terminal e ele abre. E so isso!

🎉 Seu Primeiro Momento com Claude Code

1

Abra o terminal na pasta do seu projeto

Ou crie uma pasta nova para testes

2

Digite "claude" e aperte Enter

claude
3

Siga as instrucoes de configuracao

Na primeira vez, ele vai te guiar pelo processo

🔑 Login e Autenticacao

Para usar Claude Code, voce precisa conectar sua conta Anthropic. O processo e simples e guiado.

🔐 Processo de Login

1

Crie conta em claude.ai

Se ainda nao tem, crie uma conta no site da Anthropic

2

Assine o plano Pro ($20/mes)

Voce precisa de uma assinatura ativa

3

No terminal, digite "claude" e siga o fluxo

Ele vai abrir o navegador para voce fazer login

4

Autorize o acesso

Clique em "Autorizar" no navegador e pronto!
