🆚 Diferenca Skills vs MCP

Esta e uma distincao fundamental: MCPs dao capacidade de ACAO (conectar a servicos), enquanto Skills dao CONHECIMENTO (como fazer algo bem).

🔌 MCP (Model Context Protocol)

  • • Conecta a servicos externos
  • • Permite ACOES (ler email, navegar web)
  • • E uma integracao tecnica
  • • Exemplo: Gmail MCP para enviar emails

✨ Skill

  • • Da conhecimento especializado
  • • Ensina COMO fazer algo bem
  • • E um conjunto de instrucoes/prompts
  • • Exemplo: Design Skill para criar PDFs bonitos

💡 Analogia

MCP = ferramenta (um martelo para pregar). Skill = tecnica (saber usar o martelo corretamente). Voce precisa dos dois para trabalhos de qualidade.

🌐 Skills Globais vs Projeto

Skills podem ser instalados em dois niveis: globalmente (disponiveis em todos os projetos) ou por projeto (apenas naquele projeto especifico).

Localizacao dos Skills

# Skills globais (todos os projetos)
~/.claude/skills/
├── design-skill/
├── n8n-skill/
└── writing-skill/
# Skills de projeto (apenas este projeto)
./claude/skills/
└── client-specific-skill/

Global: Quando Usar

  • • Skills de design/escrita genericos
  • • Conhecimentos que se aplicam a qualquer projeto
  • • Frameworks que voce usa sempre (n8n, etc)

Projeto: Quando Usar

  • • Conhecimento especifico de um cliente
  • • Padroes de codigo do projeto
  • • Convencoes de nomenclatura unicas

🎨 Canvas Design Skill

Um exemplo perfeito de skill util: o Canvas Design Skill ensina o agente a criar PDFs e documentos visuais com filosofia de design, fontes adequadas e formatacao profissional.

📄 O que o Skill Inclui

  • •skill.md - Instrucoes de design e melhores praticas
  • •Fontes - Pacote de fontes profissionais
  • •Templates - Estruturas de layout recomendadas
  • •Filosofia visual - Principios de hierarquia e espacamento

Antes vs Depois

Sem Skill

PDF generico, fontes padrao, sem hierarquia visual, layout desorganizado

Com Skill

Design profissional, tipografia cuidada, espacamento correto, visualmente atraente

📥 Instalacao de Skills

Skills sao instalados copiando um comando para o terminal ou pedindo ao agente. A instalacao e automatica e o agente configura tudo.

1

Encontrar o Skill

Busque no cloudcode-templates ou em repositorios da comunidade

2

Copiar Comando de Instalacao

npx @anthropic-ai/claude-code skill install canvas-design
3

Verificar Instalacao

Pergunte ao agente: "Quais skills voce tem?" para confirmar

🛠️ Criando Skills Proprios

Se voce se ve repetindo instrucoes frequentemente para o agente, transforme-as em um skill. E apenas um arquivo Markdown com suas instrucoes.

Estrutura de um Skill

# Meu Skill Customizado
## Quando Usar
Use este skill quando [situacao]...
## Instrucoes
1. Sempre faca X primeiro
2. Use o formato Y para...
3. Nunca faca Z porque...
## Exemplos
Input: "crie um relatorio"
Output esperado: [exemplo]

💡 Dica

Comece simples: anote as instrucoes que voce repete, organize em Markdown, salve em ~/.claude/skills/meu-skill/skill.md. Refine com o tempo baseado nos resultados.
