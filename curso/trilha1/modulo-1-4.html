🪣 A Analogia do Balde

Pense no contexto como um balde com capacidade fixa. Tudo que voce faz - prompts, respostas, arquivos lidos - enche esse balde. Quando fica cheio, problemas comecam.

O Balde de Tokens

30%
200K tokens

No inicio de uma sessao, seu balde esta quase vazio

📊 Numeros Importantes

  • 200.000 tokens - Capacidade total (Opus 4.5)
  • ~150.000 palavras - Equivalente aproximado
  • 1 token ≈ 4 caracteres - Em ingles (varia por idioma)
  • Portugues usa ~20% mais tokens - Que ingles
2

📊 O que Consome Contexto

Nem tudo consome contexto igualmente. Alguns itens sao "vilaoes" que esvaziam seu balde rapidamente. Conhece-los e crucial.

Consumo por Tipo

CLAUDE.md + System Prompt 5-15%
Historico de mensagens 10-30%
Arquivos lidos (Read) 20-50%
PDFs (VILAO!) 50-100%!

⚠️ O Vilao #1: PDFs

PDFs contem metadados invisiveis que consomem tokens massivamente. Um PDF de 50 paginas pode facilmente usar 1.8 milhoes de tokens - 9x mais que seu contexto inteiro! Nunca mande Claude ler PDFs grandes diretamente.

3

📉 A Regra dos 40-50%

Quando o contexto passa de 40-50%, a qualidade das respostas comeca a cair. Claude fica mais lento, menos preciso, e pode esquecer instrucoes importantes.

Guia de Uso de Contexto

0-40%
Trabalhe livremente
40-60%
Monitore, prepare compaction
60-80%
Compacte agora!
80%+
Qualidade degradada

💡 Dica de Ouro

Trate seu contexto como dinheiro. Cada token que voce gasta tem um custo. Pergunte-se: "Isso realmente precisa estar no contexto?"

4

🔍 O Comando /context

O comando /context e seu melhor amigo. Ele mostra exatamente quanto do seu balde esta cheio e o que esta ocupando espaco.

Exemplo de Saida do /context

$ /context

Context Usage: 47% (94,000/200,000 tokens)

Breakdown:

- System prompt: 8,000 tokens

- CLAUDE.md: 3,500 tokens

- Conversation: 42,000 tokens

- Files read: 40,500 tokens

✓ Quando Usar /context

  • • Antes de ler arquivos grandes
  • • Quando Claude parece lento
  • • Depois de varias interacoes
  • • Antes de tarefas complexas

Acoes Baseadas no Resultado

  • • <40%: Continue normalmente
  • • 40-60%: Evite ler mais arquivos
  • • 60-80%: Use /compact
  • • >80%: Nova sessao recomendada
5

💡 Estrategias de Economia

Existem varias tecnicas para economizar contexto e manter a qualidade das respostas por mais tempo.

🔍 Search Before Read

Sempre use Glob e Grep antes de Read. Leia apenas o necessario.

"Busque arquivos de auth antes de ler"

📦 Subagentes

Delegue tarefas para subagentes que tem contexto proprio.

"Use um subagente para explorar isso"

📄 CLAUDE.md Enxuto

Mantenha seu CLAUDE.md com menos de 300 linhas.

"Use links para playbooks externos"

🔄 Sessoes Curtas

Uma tarefa = uma sessao. Nao acumule contexto.

"Nova sessao para novo problema"

⚠️ Anti-Pattern: Ler Tudo

Nunca peca para Claude "ler todo o projeto" ou "analisar todos os arquivos". Isso vai explodir seu contexto. Seja sempre especifico sobre o que precisa ser lido.

6

🎯 Resumo das Boas Praticas

Aqui esta um checklist para gerenciar contexto como um profissional.

Checklist de Contexto

✓ Use /context regularmente
✓ Glob/Grep antes de Read
✓ Evite PDFs diretamente
✓ CLAUDE.md enxuto
✓ Compacte antes de 70%
✓ Use subagentes para explorar
✓ Nova sessao para nova tarefa
✓ Trate tokens como dinheiro
