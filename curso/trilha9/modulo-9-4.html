🎨 Meta Prompts

Crie prompts que geram prompts - a tecnica de prompt engineering para producao em massa de skills consistentes e de alta qualidade.

1

🎭 Prompt Engineer Role

Comece instruindo Claude a assumir o papel de um prompt engineer expert especializado em criar skills.

Exemplo de Role Assignment

"Agora que voce esta familiarizado com Claude Skills
e como criar SKILL.md files e Python files, quero que
voce assuma o papel de um prompt engineer.

Este prompt engineer e expert em criar pastas onde
cada pasta contem assets que podem ser importados
no Claude como skills."

💡 Por que Role Prompting?

Definir um papel especifico faz Claude adotar comportamentos e padroes consistentes, melhorando significativamente a qualidade das geracoes.

2

📐 Template para Skills

Defina um template detalhado que especifica exatamente como cada skill deve ser estruturado.

Estrutura do Template

## OUTPUT STRUCTURE

Para cada skill, voce vai criar:

1. **SKILL.md** - Definicao principal do skill
2. **demo-prompt.txt** - Como invocar o skill
3. **SETUP.md** - Instrucoes de instalacao
4. **Sample data files** - CSV/JSON para teste
5. **Zip file** - Para import no Claude.ai

📋 Secoes do SKILL.md Template

  • • What This Skill Does - Overview de 1-2 paragrafos
  • • When to Use - Lista de triggers e cenarios
  • • How It Works - Steps com codigo Python
  • • Required Libraries - Dependencias
  • • Example Usage - Prompt exemplo e outputs
3

🎛️ Variables Controlaveis

Adicione variaveis no final do meta prompt que permitem customizar: industria, quantidade, complexidade, etc.

Variaveis Padrao

## USER INPUT VARIABLES

**REQUIRED:**
- SKILL_TYPE: Descricao do skill a criar

**OPTIONAL:**
- NUM_SKILLS: Quantidade (default: 1)
- COMPANY_CONTEXT: Industria/contexto
- BRAND_COLORS: Hex codes para styling
- SPECIFIC_REQUIREMENTS: Restricoes especiais

Exemplo Simples

SKILL_TYPE: Invoice PDF to Excel
NUM_SKILLS: 1

Exemplo Complexo

SKILL_TYPE: Marketing analytics
NUM_SKILLS: 3
COMPANY_CONTEXT: SaaS B2B
BRAND_COLORS: #6366F1
4

🤔 Plan Mode para Design

Use Shift+Tab para ativar plan mode e fazer Claude propor um plano antes de gerar os skills.

Como Usar Plan Mode

1

Pressione Shift+Tab ate ver "Plan Mode"

2

Envie seu meta prompt

3

Claude propoe um plano (sem executar)

4

Ajuste conforme necessario, depois aprove

✓ Beneficios do Plan Mode

  • ✓Validar abordagem antes de gastar tokens
  • ✓Corrigir mal-entendidos cedo
  • ✓Alinhar expectativas de output
5

❓ Clarification Questions

Incentive Claude a fazer perguntas antes de gerar para garantir alinhamento completo.

Perguntas Tipicas de Claude

  • •"Voce quer zip file separado ou junto?"
  • •"Quantas linhas no sample data?"
  • •"Skills devem ser overlapping ou mutualmente exclusivos?"
  • •"Qual nivel de complexidade do Python?"

💡 Dica

Responder as perguntas de esclarecimento salva tempo e tokens - e melhor investir alguns minutos agora do que refazer depois.

6

📤 Output Format

Especifique detalhadamente como os skills gerados devem ser organizados e formatados.

Output Format Padrao

## YOUR OUTPUT FORMAT

Para cada skill criado, output:

1. **Folder name** (skill-name/)
2. **All file contents** claramente rotulados
3. **File structure summary**
4. **Installation command**

Sumario final:
📦 SKILL PACKAGE CREATED: {skill-name}
FILES INCLUDED:
✓ SKILL.md
✓ demo-prompt.txt
✓ SETUP.md
✓ sample_data.csv
✓ skill-name.zip
