CLAUDE.md do Projeto

# CLAUDE.md - Projeto Final

## Visao Geral
API RESTful em TypeScript com autenticacao JWT, CRUD de usuarios e integracao com banco PostgreSQL.

## Stack
- Runtime: Node.js 20
- Framework: Express + TypeScript
- ORM: Prisma
- Database: PostgreSQL
- Auth: JWT + bcrypt
- Tests: Jest + Supertest

## Estrutura
```
src/
├── controllers/   # Handlers de rotas
├── services/      # Logica de negocio
├── repositories/  # Acesso a dados
├── middlewares/   # Auth, validation
├── types/         # TypeScript types
└── utils/         # Helpers
```

## Convencoes
- Controllers: PascalCase + "Controller" (UserController)
- Services: PascalCase + "Service" (AuthService)
- Testes: mesmo nome + .test.ts
- Commits: Conventional Commits (feat:, fix:, etc)

## Comandos
- `npm run dev` - Desenvolvimento
- `npm run test` - Testes
- `npm run build` - Build
- `npm run lint` - Linting

## Regras
1. NUNCA commitar .env
2. Todas rotas requerem validacao de input
3. Erros devem retornar formato padrao: { error: string, code: string }
4. Cobertura de testes minima: 80%

Atualizado: 2026-01-31

💡 Exercicio

Crie um novo diretorio, inicialize com npm init -y, e crie o CLAUDE.md acima. Execute claude /init para ver as sugestoes de melhoria.

🪝 Hooks de Automacao

Configure hooks para automatizar validacoes e notificacoes.

.claude/hooks/pre-edit.sh

#!/bin/bash
# Proteger arquivos criticos

PROTECTED=(
  "prisma/schema.prisma"
  ".env"
  ".env.*"
  "package-lock.json"
)

for pattern in "${PROTECTED[@]}"; do
  if [[ "$CLAUDE_FILE" == $pattern ]]; then
    echo "PROTEGIDO: $CLAUDE_FILE"
    echo "Edite manualmente."
    exit 1
  fi
done

# Backup automatico
if [ -f "$CLAUDE_FILE" ]; then
  mkdir -p .claude/backups
  cp "$CLAUDE_FILE" ".claude/backups/$(basename $CLAUDE_FILE).$(date +%s).bak"
fi

exit 0

.claude/hooks/post-edit.sh

#!/bin/bash
# Auto-format e stage

# Formatar TypeScript
if [[ "$CLAUDE_FILE" =~ \.tsx?$ ]]; then
  npx prettier --write "$CLAUDE_FILE" 2>/dev/null
fi

# Auto-stage
if git rev-parse --git-dir > /dev/null 2>&1; then
  git add "$CLAUDE_FILE"
  echo "Staged: $CLAUDE_FILE"
fi

# Log de atividade
echo "$(date): $CLAUDE_ACTION $CLAUDE_FILE" >> .claude/activity.log

💡 Importante

Torne os scripts executaveis com chmod +x .claude/hooks/*.sh

🔄 CI/CD Pipeline

Configure o pipeline que integra Claude no fluxo de Pull Requests.

.github/workflows/claude-ci.yml

name: Claude CI

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  lint-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm ci
      - run: npm run lint
      - run: npm run test -- --coverage

  claude-review:
    runs-on: ubuntu-latest
    needs: lint-test
    permissions:
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }

      - name: Install Claude
        run: npm install -g @anthropic-ai/claude-code

      - name: Get Diff
        id: diff
        run: |
          DIFF=$(git diff origin/${{ github.base_ref }}...HEAD -- '*.ts' | head -c 10000)
          echo "diff<> $GITHUB_OUTPUT
          echo "$DIFF" >> $GITHUB_OUTPUT
          echo "EOF" >> $GITHUB_OUTPUT

      - name: Claude Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          claude --print "Review este diff de PR:
          ${{ steps.diff.outputs.diff }}

          Use o formato:
          ## Score: X/10
          ## Issues
          ## Aprovado: Sim/Nao" > review.md

      - name: Comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const review = fs.readFileSync('review.md', 'utf8');
            github.rest.issues.createComment({
              owner: context.repo.owner,
              repo: context.repo.repo,
              issue_number: context.issue.number,
              body: '## 🤖 Claude Review\n\n' + review
            });
