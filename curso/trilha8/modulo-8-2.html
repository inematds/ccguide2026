📝 CLAUDE.md e System Prompt

Configure o arquivo CLAUDE.md para guiar Claude Code em projetos de conversao n8n para web apps. Um system prompt bem escrito elimina repeticoes e garante consistencia.

📄 Criar claude.md

O arquivo claude.md funciona como system prompt para o projeto. Ele define o que estamos fazendo, quais tecnologias usar e quais regras seguir.

📋 Exemplo de claude.md para n8n-to-app

# Projeto: n8n to Web App

## Objetivo
Transformar workflows n8n em aplicacoes web funcionais.

## Processo
1. Analisar workflow n8n via MCP
2. Otimizar para conexao com front-end
3. Construir interface web
4. Testar localmente
5. Deploy via Vercel

## Tecnologias
- Front-end: Tailwind CSS
- Repos: Separados por app
- Deploy: Vercel + GitHub

## MCP Servers
- n8n MCP (czlonkowski/n8n-mcp)
- GitHub MCP

## Regras
- Perguntar antes de fazer mudancas grandes
- Manter arquivos concisos
- Documentar decisoes importantes

💡 Dica Pratica

Voce pode pedir para Claude ajudar a escrever o claude.md! Use plan mode e descreva o que quer fazer - ele fara perguntas e criara o arquivo.

2

🔵 Plan Mode para Setup

O plan mode (azul) faz Claude pensar mais antes de agir. Ele faz perguntas, propoe planos e so executa quando voce aprovar.

🔵

Plan Mode

Pensa e pergunta antes de agir. Ideal para setup inicial e planejamento.

🟠

Bypass Mode

Executa sem confirmar cada acao. Bom para tarefas de confianca.

⚪

Auto Mode

Aceita tudo automaticamente. Use com cuidado!

📊 Quando usar Plan Mode

  • Setup inicial: Configurando novo projeto
  • Arquitetura: Decidindo estrutura do app
  • Integracao: Conectando MCPs e skills
  • Mudancas grandes: Refatoracoes significativas
3

❓ Clarification Questions

Em plan mode, Claude faz perguntas de esclarecimento antes de agir. Responda com clareza para obter resultados melhores.

Perguntas Tipicas

Claude pergunta:

"Qual a estrutura tipica dos workflows que voce quer converter?"

Boa resposta:

"Variados triggers - alguns com chat trigger, outros com webhooks. Maioria usa AI agents."

Claude pergunta:

"Prefere um repo por app ou todos no mesmo repo?"

Boa resposta:

"Repos separados - facilita deploy individual e controle de versao."

4

⚡ Auto-accept Changes

O modo bypass permissions aceita mudancas automaticamente. Isso acelera muito o desenvolvimento quando voce confia no que Claude esta fazendo.

1

Habilitar nas Settings

Abra settings do VS Code, busque "claude code" e marque "Allow dangerously skip permissions"

2

Selecionar Bypass Mode

No chat do Claude Code, clique no modo e selecione "Bypass permissions" (laranja)

⚠️ Atencao

Bypass mode executa comandos sem confirmacao. Sempre acompanhe o que Claude esta fazendo e esteja pronto para interromper se necessario.

📋 Guidelines Claras

Documente regras e padroes no claude.md. Isso garante consistencia mesmo quando Claude toma decisoes autonomas.

Incluir no claude.md

  • ✓CSS framework preferido (Tailwind)
  • ✓Estrategia de repos (separados)
  • ✓Plataforma de deploy (Vercel)
  • ✓MCPs e Skills a usar

Evitar

  • ✗Arquivos muito longos
  • ✗Instrucoes vagas
  • ✗Contradições
  • ✗Detalhes irrelevantes
